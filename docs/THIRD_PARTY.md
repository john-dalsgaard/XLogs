# Third-party components and attribution

The original project's `NOTICE.txt` and MIT license files have been retained. This inventory records components present in the source tree; it is not a completed licensing audit.

| Component | Location | License / attribution |
| --- | --- | --- |
| Apache Commons Lang 3.1 | `nsf/Code/Jars/commons-lang3-3.1.jar` | Apache 2.0; preserve embedded LICENSE and NOTICE |
| Apache Commons IO 2.2 | `nsf/Code/Jars/commons-io-2.2.jar` | Apache 2.0; preserve embedded LICENSE and NOTICE |
| jQuery 2.0.3 | `nsf/Resources/Files/jquery-2.0.3.min.js` | MIT; see root jQuery license file and embedded header |
| TableSorter | `nsf/Resources/Files/tablesorter_2fjquery.tablesorter.min.js` and related resources | See root TableSorter MIT license file and embedded notices |
| A simple XML Parser | `nsf/Code/Java/dk/xpages/utils/XML.java`; credited by the original project | Original permission statement and source URL are retained in NOTICE.txt |
| Original icons | Image resources inherited from the original application | Original NOTICE credits findicons.com under Creative Commons Attribution |

Before a public release, identify the original icon authors and exact license versions where possible, confirm the provenance of newer artwork including the XLogs icon, and verify the XML parser's original permission against its source. The inherited generic icon notice does not identify individual assets or their authors. Keep original attribution while this is resolved.

When distributing a database, include the root license files and NOTICE alongside it, and retain component notices within the database and bundled JARs.
